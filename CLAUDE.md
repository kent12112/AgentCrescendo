# Repository instructions for Claude

Read [the shared development workflow](docs/coordination.md) and
[current status](docs/status.md) before starting work. Read handoffs relevant to
the requested task. Follow these instructions alongside the user's request.

Use [architecture](docs/architecture.md) for design intent and
[implementation plan](docs/implementation-plan.md) for scope and exit criteria.
Check the implementation and evidence before treating planned behavior as done.

Follow the learning workflow in the implementation plan: explain shell commands
before running them, connect results to the concept being learned, and document
consequential decisions and observed failures.

Update status and leave a handoff after meaningful work. Never assume another
agent has read a message or accepted an assignment. Do not launch another agent
unless the user explicitly requests delegation.
